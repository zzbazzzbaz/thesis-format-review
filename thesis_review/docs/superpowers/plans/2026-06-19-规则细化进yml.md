# 规则细化进 yml Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的毕业设计格式规则拆分到 `thesis_review/docs/rules/**/rule.yml` 和少量人工样本清单 `case.yml` 中。

**Architecture:** 规则资产仍由现有 catalog loader 加载，运行时只读取 `rule.yml`，测试和人工样本维护读取 `case.yml`。新增规则全部先标记为 `draft`，现有目录规则保持 `active`，避免未实现检查器参与正式审核。每个新增模块只写 1 个代表性 `case.yml` 条目，降低人工制作 Word 样本成本。

**Tech Stack:** Python 3.12, PyYAML, Pydantic v2, pytest, uv。
