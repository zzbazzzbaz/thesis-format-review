# 产品侧前端设计

日期：2026-07-01
状态：待评审

## 1. 背景与目标

毕业设计格式审核系统采用前后端分离架构。产品侧后端已经负责用户登录、角色权限、学生次数、审核任务、文件下载和教师统计；前端只调用产品侧 Django API，不直接访问 `thesis_review` 服务。

前端目标：

1. 建设 PC 端 Web 管理/使用界面。
2. 支持学生端上传 Word、查看审核进度、下载审核结果、查看历史记录、查看个人信息和剩余次数。
3. 支持教师端查看自己学生的上传情况、下载学生上传 Word 和审核结果、查看统计信息。
4. 基于 JWT 做登录态管理和角色路由隔离。
5. 使用 Vue 3、TypeScript、Tailwind CSS 实现清晰、稳定、适合重复使用的工作台界面。

## 2. 范围边界

### 2.1 前端职责

前端负责：

- 登录页面和登录态维护。
- 根据用户角色进入学生端或教师端。
- 学生端上传 `.docx` 文件。
- 展示学生剩余审核次数，上传成功后刷新个人信息和任务列表。
- 展示任务状态、进度、问题摘要和失败原因。
- 轮询待处理任务详情，直到任务成功或失败。
- 下载原始 Word、标注 Word 和 `issues.json`。
- 教师端展示自己学生的任务列表、筛选条件、任务详情和统计信息。
- 统一展示加载中、空状态、错误状态、权限失败和会话过期状态。

### 2.2 前端不负责

前端不负责：

- 直接调用 `thesis_review`。
- 本地解析 `.docx` 内容。
- 本地计算审核问题。
- 本地扣减次数；次数扣减由后端在任务创建事务中完成。
- 绕过后端鉴权直接访问文件路径。
- 移动端、小程序端或响应式移动适配。

## 3. 技术选型

前端使用：

- Vue 3。
- TypeScript。
- Vite。
- Vue Router。
- Pinia。
- Tailwind CSS。
- 原生 `fetch` 或 Axios 二选一；首版建议 Axios，便于统一拦截 401、下载 Blob 和设置 Authorization。

实现约定：

- Vue 单文件组件使用 `<script setup lang="ts">`。
- Tailwind CSS 使用 Vite 插件方式集成；样式入口使用 `@import "tailwindcss";`。
- PC 端优先，不做移动端断点适配；最低内容宽度建议按 `1280px` 工作台设计。
- 不引入大型 UI 框架作为首版必需依赖；可以用 Headless 组件或轻量自定义组件实现表格、弹窗、按钮和表单。

## 5. 用户与权限

### 5.1 角色

| 角色 | 前端入口 | 权限 |
|---|---|---|
| 学生 | `/student` | 上传自己的论文，查看自己的任务、历史、下载自己的文件和结果，查看个人信息和剩余次数。 |
| 教师 | `/teacher` | 查看绑定到自己的学生任务，下载这些学生的原始 Word 和结果，查看统计。 |
| 管理员 | Django Admin | 不通过 Vue 前端实现管理功能。 |

### 5.2 登录态

登录成功后保存：

- `access` token。
- `refresh` token。
- 当前用户基础信息：`id`、`username`、`name`、`role`。

存储策略：

- 首版可以使用 `localStorage`。
- Axios 请求拦截器统一添加 `Authorization: Bearer <access>`。
- 如果接口返回 401，优先尝试 refresh；refresh 失败则清空登录态并跳转登录页。

### 5.3 路由守卫

路由守卫规则：

- 未登录访问业务页面：跳转 `/login`。
- 学生访问教师页面：跳转学生首页或显示 403。
- 教师访问学生页面：跳转教师首页或显示 403。
- 已登录访问 `/login`：根据角色跳转默认首页。

## 6. 页面设计

界面风格定位：

- PC 工作台，不做营销页。
- 左侧固定导航，顶部显示用户姓名、角色和退出登录。
- 主区域使用紧凑、清晰的表格、筛选栏、统计卡和详情面板。
- 卡片圆角不超过 8px。
- 避免大面积单一色系背景；主色用于交互状态，内容区域保持白色/浅灰。
- 文本不要遮挡或溢出；文件名、错误信息和下载按钮需要处理长文本。

### 6.1 登录页

路径：`/login`

功能：

- 用户名输入。
- 密码输入。
- 登录按钮。
- 登录失败提示。
- 登录中禁用按钮。

成功后：

- 学生跳转 `/student`。
- 教师跳转 `/teacher`。
- 管理员提示“请使用后台管理入口”，或跳转 `/admin/`。

### 6.2 学生端工作台

路径：`/student`

内容：

- 顶部统计：
  - 姓名。
  - 学号。
  - 专业/班级。
  - 指导教师。
  - 剩余审核次数。
- 最近任务列表。
- 存在 `pending` 或 `running` 任务时显示进度状态。
- 上传入口按钮。

交互：

- 点击上传入口进入上传页。
- 点击任务进入详情页。
- 最近任务中成功任务可直接下载标注 Word 和 `issues.json`。

### 6.3 学生上传页

路径：`/student/upload`

功能：

- 显示当前剩余审核次数。
- 文件选择或拖拽上传，只允许 `.docx`。
- 显示待上传文件名、大小。
- 上传按钮。
- 上传成功后显示任务 ID 和状态，并引导进入任务详情。

校验：

- 未选择文件不能提交。
- 非 `.docx` 文件前端拦截并提示。
- 剩余次数为 0 时禁用上传入口并提示“剩余审核次数不足”。

注意：

- 上传成功后后端已经扣减一次次数；前端必须刷新个人信息。
- 上传失败不应在前端扣减次数。

### 6.4 学生任务详情页

路径：`/student/tasks/:id`

内容：

- 文件名。
- 状态：等待审核、正在审核、审核完成、审核失败。
- 进度条：`0`、`20`、`90`、`100`。
- 问题摘要：总数、错误、警告、提示。
- 提交时间、开始时间、完成时间。
- 失败原因。
- 下载区：
  - 原始 Word。
  - 标注 Word。
  - `issues.json`。

交互：

- `pending`、`running` 状态自动轮询详情。
- `succeeded` 状态启用全部下载。
- `failed` 状态显示失败原因，不显示结果下载。
- 下载结果未生成时如果后端返回 409，前端提示“审核结果尚未生成”。

### 6.5 学生历史记录页

路径：`/student/history`

功能：

- 分页任务表格。
- 状态筛选。
- 文件名展示。
- 提交时间、完成时间、问题摘要。
- 操作列：
  - 查看详情。
  - 下载原文。
  - 成功任务下载标注 Word。
  - 成功任务下载 `issues.json`。

空状态：

- 无历史任务时显示“暂无审核记录”，并提供上传入口。

### 6.6 学生个人信息页

路径：`/student/profile`

内容：

- 姓名。
- 学号。
- 学院。
- 专业。
- 班级。
- 指导教师。
- 剩余审核次数。

说明：

- 首版只读，不提供编辑。
- 剩余次数由后端维护，上传成功后需要刷新该页面数据。

### 6.7 教师端工作台

路径：`/teacher`

内容：

- 统计卡：
  - 学生总数。
  - 已提交学生数。
  - 任务总数。
  - 成功任务数。
  - 失败任务数。
  - 平均问题数。
- 最近提交列表。
- 快捷入口：查看全部提交。

### 6.8 教师任务列表页

路径：`/teacher/tasks`

功能：

- 查看自己学生的上传任务。
- 表格字段：
  - 学生姓名。
  - 学号。
  - 班级。
  - 文件名。
  - 状态。
  - 问题摘要。
  - 提交时间。
  - 完成时间。
  - 操作。
- 筛选条件：
  - 学号。
  - 学生姓名。
  - 状态。
  - 提交开始日期。
  - 提交结束日期。
- 操作：
  - 查看详情。
  - 下载学生上传 Word。
  - 成功任务下载标注 Word。
  - 成功任务下载 `issues.json`。

权限原则：

- 教师只能看到后端返回的自己学生任务。
- 前端不构造或展示其他教师学生数据入口。
- 学生信息只展示后端返回字段；首版教师任务列表不额外展示学院、专业等后端未返回字段。

### 6.9 教师任务详情页

路径：`/teacher/tasks/:id`

内容：

- 学生信息：姓名、学号、班级。
- 文件名。
- 状态、进度、问题摘要。
- 时间信息。
- 失败原因。
- 下载区：原始 Word、标注 Word、`issues.json`。

状态处理：

- 如果任务不存在或无权访问，后端返回 404，前端显示“任务不存在或无权访问”。
- 成功任务显示结果下载。
- 未完成任务只显示原始 Word 下载。

## 9. 下载处理

因为下载接口需要 JWT 鉴权，前端不要直接把下载地址放入普通 `<a href>` 并依赖浏览器访问。

推荐下载流程：

1. 使用 API client 发送带 `Authorization` 的 GET 请求。
2. 响应类型使用 Blob。
3. 从响应头或前端约定生成文件名。
4. 创建临时 object URL。
5. 触发浏览器下载。
6. 释放 object URL。

错误处理：

- 401：会话过期，跳转登录。
- 404：文件不存在或无权访问。
- 409：审核结果尚未生成。
- 其他错误：显示“下载失败，请稍后重试”。

## 10. 任务轮询

轮询对象：

- 学生任务详情页中的当前任务。
- 学生工作台中的 `pending` / `running` 最近任务。

轮询规则：

- `pending` / `running`：每 3 秒请求一次详情。
- `succeeded` / `failed`：停止轮询。
- 页面离开时停止轮询。
- 浏览器标签页不可见时暂停或降低频率。
- 连续失败 3 次后停止轮询并提示网络异常。

## 11. 状态与错误文案

### 11.1 任务状态

| 后端状态 | 前端文案 | 展示 |
|---|---|---|
| `pending` | 等待审核 | 灰色标签，进度 0 |
| `running` | 正在审核 | 蓝色标签，显示进度条 |
| `succeeded` | 审核完成 | 绿色标签，允许下载结果 |
| `failed` | 审核失败 | 红色标签，显示失败原因 |

### 11.2 常见错误

| 场景 | 文案 |
|---|---|
| 未登录 | 请先登录 |
| 会话过期 | 登录已过期，请重新登录 |
| 非 `.docx` 文件 | 仅支持上传 .docx 文件 |
| 剩余次数不足 | 剩余审核次数不足，请联系管理员 |
| 上传失败 | 上传失败，请稍后重试 |
| 任务不存在 | 任务不存在或无权访问 |
| 下载结果未生成 | 审核结果尚未生成 |
| 服务异常 | 服务暂不可用，请稍后重试 |

## 13. 性能与体验

- 表格分页由后端完成，前端不一次性拉取全部任务。
- 下载大文件时显示按钮 loading 状态。
- 上传时显示进度状态；首版如果无法获得真实上传进度，至少显示“上传中”。
- 任务轮询只对未完成任务启用。
- 切换页面时取消未完成请求，避免状态覆盖。
- 时间统一格式化为 `YYYY-MM-DD HH:mm`。
- 文件名过长时中间截断，悬停显示完整名称。

## 14. 安全要求

- 不在 URL 查询参数中传递 token。
- 不把 refresh token 写入日志。
- 下载必须走后端接口，不拼接 media 静态路径。
- 教师端不保存或展示后端未返回的其他教师学生信息。
- 前端权限控制只用于体验优化，最终权限以后端返回为准。
- 退出登录时调用后端 logout，并清空本地 token。

## 15. 测试策略

建议测试层级：

- 类型检查：`vue-tsc --noEmit`。
- 单元测试：
  - 状态文案映射。
  - 下载工具函数。
  - API client 401 refresh 逻辑。
  - 轮询停止逻辑。
- 组件测试：
  - 上传页文件校验。
  - 任务表格状态展示。
  - 教师筛选条件构造。
- E2E 测试：
  - 学生登录、上传、查看任务、下载。
  - 学生历史记录筛选和分页。
  - 教师登录、查看任务、下载文件、查看统计。
  - 角色越权访问跳转。

## 16. 验收标准

- 学生可以登录并进入学生端。
- 学生可以看到个人信息和剩余审核次数。
- 学生只能上传 `.docx` 文件。
- 上传成功后任务进入列表，剩余次数刷新并减少 1。
- 学生可以查看任务进度，任务完成后下载标注 Word 和 `issues.json`。
- 学生可以查看历史记录并下载历史文件。
- 教师可以登录并进入教师端。
- 教师可以查看自己学生的上传情况。
- 教师可以按学生、状态、提交时间筛选任务。
- 教师可以下载学生上传 Word 和审核结果。
- 教师可以查看统计信息。
- 学生不能访问教师页面，教师不能访问学生页面。
- 401、403、404、409 等错误都有明确界面反馈。
- PC 端主要页面在 1280px 及以上宽度无布局错乱、文字重叠或按钮溢出。

## 17. 首版明确不做

- 不提供管理员入口按钮跳转 Django Admin。
- 教师端不支持导出统计报表。
- 不在前端预览 `issues.json`，首版只提供下载。
- 教师端学生信息只展示后端返回字段；当前任务列表展示姓名、学号、班级。
