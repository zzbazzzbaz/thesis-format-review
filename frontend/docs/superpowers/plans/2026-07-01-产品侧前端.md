# 产品侧前端 Implementation Plan

> **For agentic workers:** 本计划用于实现产品侧 Vue 前端。严格遵循对应设计文档：`frontend/docs/superpowers/specs/2026-07-01-产品侧前端-design.md`。实现范围仅包含 PC 端学生端和教师端，不实现管理员前端入口、不实现统计导出、不预览 `issues.json`。

**Goal:** 建设产品侧 PC Web 前端，由 Vue 应用负责登录、角色路由、学生上传与历史、任务进度与下载、教师任务查看与统计。前端只调用 Django 产品后端 API，不直接访问 `thesis_review`。

**Architecture:** 前端使用 Vue 3 单页应用。Axios 统一封装 API、JWT、401 refresh 和 Blob 下载；Pinia 保存登录态和必要的页面状态；Vue Router 做学生端和教师端路由隔离；Tailwind CSS 构建紧凑清晰的 PC 工作台界面。

**Tech Stack:** Vue 3、TypeScript、Vite、Vue Router、Pinia、Tailwind CSS、Axios、Vitest、Vue Test Utils、Playwright。

**执行目录:** 除特别说明外，所有命令从 `frontend/` 目录运行。

## Important Considerations & Requirements

- [ ] 只适配 PC 端，不做移动端或小程序端。
- [ ] 使用 Vue 3、TypeScript、Tailwind CSS。
- [ ] 使用 `npm` 管理依赖。
- [ ] 使用 `<script setup lang="ts">`。
- [ ] 前端只调用 Django 产品后端 API。
- [ ] 不直接调用 `thesis_review`。
- [ ] 不在前端扣减次数，上传成功后刷新后端返回的剩余次数。
- [ ] 下载必须走带 JWT 的后端接口，不使用公开 media URL。
- [ ] 不提供管理员入口按钮跳转 Django Admin。
- [ ] 教师端不支持导出统计报表。
- [ ] 不预览 `issues.json`，首版只下载。
- [ ] 教师端学生信息只展示后端返回字段。
- [ ] 不添加占位 TODO 代码。
- [ ] 不过度抽象，优先完成稳定可用的首版工作台。

## Technical Decisions

- [ ] Vue Router 用于角色路由隔离，后端仍是最终权限来源。
- [ ] Pinia 保存认证状态和当前用户，不保存敏感调试日志。
- [ ] Axios 统一处理 Authorization、refresh 和 Blob 下载。
- [ ] Tailwind CSS 负责视觉系统和布局，不引入大型 UI 框架作为首版必需依赖。
- [ ] 表格分页、筛选由后端完成，前端不一次性拉取全部任务。
- [ ] 轮询仅对未完成任务启用，页面离开后必须停止。

## Testing Strategy

- [ ] 类型检查覆盖全部源码。
- [ ] 单元测试覆盖状态映射、格式化、下载工具、API client 和轮询逻辑。
- [ ] 组件测试覆盖登录、上传校验、任务表格、统计卡和错误状态。
- [ ] E2E 测试覆盖学生端和教师端关键路径。
- [ ] E2E 可以使用 mock API 进行快速验证；完整联调再连接真实 Django 后端、worker 和 `thesis_review`。

## Debugging Protocol

- **登录失败**：检查 `/api/auth/login/` 响应、token 保存、Authorization header 和角色跳转。
- **会话刷新失败**：检查 refresh token 是否存在、是否被后端注销、Axios 拦截器是否重复请求。
- **上传失败**：检查文件后缀、FormData 字段名 `file`、剩余次数和后端 400 消息。
- **任务一直 pending**：检查后端 `review_worker` 是否运行，不在前端伪造成功状态。
- **下载失败**：检查 Blob 请求是否带 Authorization、后端状态码是否为 409/404/401。
- **教师看不到数据**：检查教师账号是否绑定学生、筛选参数是否正确。
- **布局错乱**：先在 1280px 宽度复现，检查表格列宽、长文件名截断和按钮文本宽度。
